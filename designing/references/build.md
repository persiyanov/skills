# A running build

- **Build with the product's own components and tokens,** on a branch, with real data, a test login for each role, and a way to reach each state.
- **Forks are variants behind a switch** in the real page, one shown at a time, so that the user flips between them (Emil Kowalski, "prototype"; interfaces plugin, "variant").
- **A value that people judge by feel,** such as a duration or a density, gets a live control (Interface Craft, "Live Tuning").
- **Commit before you fix a review's findings,** so that the verifier can compare before and after.
- **Show the user screenshots,** with the address and the steps that reach each state.
- **Measure from the DOM,** with design-knowledge's `scripts/style-inventory.js`, never from a screenshot's pixels.
