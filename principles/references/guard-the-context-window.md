# Guard the Context Window

Keep the evidence and decisions that you need in reach, because large outputs and repeated reads crowd out useful context.

- Search, filter, and read the relevant sections before you load whole files or payloads.
- Use focused delegation when it helps, accounting for the effort of coordination.
- Keep access to original sources. Summaries save space but can lose details that matter.
- Put instructions that every invocation needs in the skill itself, and keep occasional detail in references.
- Before a handoff or loss of context, record the objective, constraints, decisions, evidence locations, and remaining work.

For example, search a 2 MB log for the error's ID before you read it, and note the line numbers, so that you can go back to the source.

Ask: What do I need in reach to finish, and what is crowding it out?
