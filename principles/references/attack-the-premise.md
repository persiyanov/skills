# Attack the Premise

Suspect the premise, not the next fix. When fixes that share one premise fail the same check, each failure is evidence about the premise. Write it down: the one sentence every failed fix assumed. Do not start the next fix until it is written.

Then test the sentence. Name the observation that would disprove it and go and get it: [Fix Root Causes](fix-root-causes.md). If the premise holds, look elsewhere and keep the evidence. If it falls, design from the corrected fact instead of around the old one: [Radical Simplicity](radical-simplicity.md).

Ask: What sentence did every failed fix assume, and what would disprove it?
